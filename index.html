About me

I started out as a backend engineer on fintech and enterprise platforms, where I learned to care about tests, code reviews and catching problems before users do. Moving into AI evaluation felt like a natural next step: the question is the same, only the system being tested has changed.

Being both a builder and a tester shapes how I work. When a benchmark says an agent failed, I want to know whether the agent was wrong or the test was. Next, I want to take more ownership of how AI initiatives are planned and delivered, and grow toward technical leadership.
